# 这句话，我想重说 · 完整参赛版 v1.0

> 有些话，可以重新说。把话说清楚，也把自己照顾好。

## 交付内容

| 路径 | 用途 |
| --- | --- |
| `一键预览.html` | 自带全部样式、代码和插画；下载后直接双击打开，无需 Node.js 或联网 |
| `dist/` | 已构建、可部署网页；入口 `index.html`，另有 `standalone.html` 单文件版 |
| `src/app.js` | 七步交互、记录、导出与隐私逻辑 |
| `src/data.js` | 五个原创故事、目标、物件、预设分支与参考句 |
| `src/style.css` | 纸感鼠尾草绿视觉、桌面和移动端样式、减少动态效果支持 |
| `assets/` | 五张原创场景 SVG 插画与作品标志 |
| `scripts/` | 无第三方依赖的构建和静态预览服务 |
| `tests/` | 内容/交付检查及可选真实浏览器测试 |
| `docs/` | 作品介绍、秒哒说明、验证证据和截图 |

## 体验结构

进入故事 → 选择目标 → 两轮交流 → 私人暂停 → 重说一句 → 原版/新版对比 → 结束回顾。

五个故事：

1. **宿舍 · 凌晨一点的灯**：休息需要与共同作息。
2. **家庭 · 饭桌上的那句关心**：在关心与比较中表达自主需要。
3. **代签 · “就帮我签一次嘛”**：坚定拒绝违规请求，保留合规帮助。
4. **朋友 · 又一次等到天黑**：表达失落并约定时间边界。
5. **恋爱 · 已读之后的沉默**：区分事实与猜测，商量联系节奏。

每个场景有三个可点击物件；对话提供两条预设分支；私人暂停提供舒缓呼吸动画、需要辨认与自我提醒。自由编辑支持 2–500 个字符（按 JavaScript 字符串长度计算）；可选择参考句。系统展示固定结局并明确解释其局限，最后手动保存练习。

## 一键预览

双击根目录 `一键预览.html`。所有内容已内联，浏览器无需访问网络。部分浏览器对 `file:` 页面的存储策略不同；如果本地记录受限，作品会提示，请改用静态服务并导出备份。

如果文件页面受到浏览器策略限制，可双击 `一键启动.cmd`（Windows）或 `一键启动.command`（macOS，需允许脚本执行），脚本将构建并启动本地服务、尝试打开浏览器。此方式需要安装 Node.js；Linux 可执行 `sh 一键启动.command`。受限设备可直接运行下方命令。

## 构建与本地开发

需要 Node.js ≥20。运行作品不需要 npm install，没有第三方生产依赖，也不需要模型、API 密钥、数据库或 Python 服务。

```sh
cd competition
npm run build
npm test
npm run preview
```

默认端口 4173，可通过环境变量 `PORT` 调整。预览服务监听 `0.0.0.0`，方便局域网手机测试；请在可信网络使用。停止服务按 Ctrl+C。修改 `src/` 或 `assets/` 后再次构建并刷新，无需重新安装。构建会替换生成的 `dist/` 和 `一键预览.html`，请修改源文件，不要直接修改生成文件。

## 独立部署

- 把 `dist/` 的内容上传至任意支持静态 HTML 的托管服务；入口是 `index.html`。
- 支持子路径部署，资源均为相对路径，无前端路由重写要求。
- 也可仅发布 `dist/standalone.html`，改名为 `index.html`。该文件已包含全部插画、CSS 和 JavaScript。
- 推荐 HTTPS。没有后台请求，没有鉴权或服务器环境变量。
- 模块版须通过 HTTP(S) 服务访问；直接双击时使用 `一键预览.html`。
- 自托管若配置 CSP，模块版只需同源脚本/样式/图片；单文件版使用内联模块和样式、data: 图片，应依托宿主平台的代码导入支持配置相应策略，不要默认移除平台安全限制。

## 本地记录与边界

存储键 `respeak.practice.v1`。仅保存完成后用户点击保存的记录，含场景、目标、需要、前后表达、回顾感受和时间。私人暂停的自我提醒不写入记录。不调用任何外部 API，不放置统计或追踪脚本。

可导出版本化 JSON 文件，逐条删除需确认。当前版本不提供 JSON 导入或跨设备同步。更换浏览器、域名、端口或本地文件位置可能产生独立记录；清理浏览器数据或无痕模式会导致丢失。存储失败时记录仅暂存内存并提示导出。请勿输入身份信息等敏感内容。

故事回应和结局均为预设文字，不会分析自由输入，不能预测现实关系的结果。本作品不提供心理诊断或专业咨询；面对控制、威胁或暴力，应优先保护安全并寻求支持。

## 验证

`npm test` 执行 3 项内容与构建交付检查。真实浏览器测试 `tests/browser.cjs` 需要另外安装 Playwright 与 Chromium（只是开发检查工具，不是作品运行依赖）：

```sh
npm install --prefix /tmp/respeak-test-tools playwright
NODE_PATH=/tmp/respeak-test-tools/node_modules CHROMIUM_PATH=/usr/bin/chromium node tests/browser.cjs
```

先启动预览服务；可设置 `BASE_URL`。Windows 请使用对应环境变量语法与 Chromium 路径。详见[验证报告](./docs/验证报告.md)。

## 打包复现

在仓库根目录运行，ZIP 内含一个 `competition/` 顶层文件夹：

```sh
cd competition
npm run build
npm test
cd ..
zip -r respeak-competition-v1.0.0.zip competition -x '*/node_modules/*' '*.DS_Store'
```

首次打包或重新生成前，请移走旧 ZIP，避免 zip 更新模式保留已删除条目。本次交付没有第三方字体、远程图片或收费素材。代码、文字与原创 SVG 插画依照仓库 MIT 许可证使用。
