# 《这句话，我想重说》

**作品定位：** 以日常沟通为主题的互动叙事与表达练习网页。

**一句话介绍：** 把脱口而出的那句气话，变成一次看见自己、表达需要的机会。

## 创作出发点

许多关系里的摩擦不是没有在意，而是在意被情绪遮住了。我们想争取安静，先说出责备；我们希望被理解，却先推开对方。《这句话，我想重说》把这些瞬间变成可进入、可停顿、可重来的小故事。它不替用户评判谁对谁错，也不以“完美话术”保证关系改善，而是让用户拥有多一种表达选择。

## 核心体验

用户从宿舍、家庭、代签、朋友、恋爱五段生活切片中选择故事。每段场景配有原创矢量插画和三个可点物件，让环境细节成为观察事实、理解需要的线索。接着选择本次目标，体验两轮预设交流；进入只属于自己的暂停空间，慢慢呼吸，辨认此刻需要什么；最后用自己的话重写一句，在同一屏看到原版与新版，并留下回顾。

本作品明确标注所有剧情与人物回应均为预设，不把固定结局伪装成对用户输入的智能反馈。写下的句子只属于练习者，完成后可选择留在本地手记中。

## 作品亮点

- **完整的情绪到表达闭环**：从冲突触发到暂停、需要辨认、重新表达，再到回顾，不只提供一句模板。
- **边界也是表达的一部分**：代签场景鼓励拒绝不当请求；亲密关系场景提醒沟通不应替代安全保护。
- **空间叙事**：灯、闹钟、汤碗、课程表、冷咖啡与雨窗，把抽象的表达原则变成可发现的细节。
- **诚实的预设剧情设计**：无需模型或密钥，无随机回复；参考句是脚手架，不是打分标准。
- **低门槛且重视隐私**：无登录、无后端、无上传；本地保存、逐条删除、JSON 导出。
- **可独立交付**：源码、静态部署版、离线单文件、一键预览、移动端布局与验证证据齐备。

## 视觉与实现

米白纸感底色、鼠尾草绿、陶土暖色与手绘风原创 SVG 插画，营造一间安静的“故事小屋”。原生 JavaScript 模块驱动七步状态流转；CSS 响应式覆盖桌面与手机，支持键盘聚焦、语义化控件、对话框和减少动态效果偏好。Node.js 仅用于构建/预览，实际运行仅需浏览器。

## 约两分钟展示脚本

1. **0:00–0:20** 首页介绍：“有些话，可以重新说。”展示五段故事与预设剧情标识。
2. **0:20–0:40** 进入“凌晨一点的灯”，点击台灯、闹钟，解释物件如何引导观察事实。
3. **0:40–1:00** 选择休息目标，体验预设对话，看到责备或温和表达带来的不同分支。
4. **1:00–1:20** 进入私人暂停，选择“安静与休息”和自我提醒。
5. **1:20–1:40** 输入自己的新表达，或使用参考句作为起点；展示原版与新版对比，以及“固定结局”的说明。
6. **1:40–2:00** 完成回顾、保存记录、刷新查看；切换手机尺寸，展示本地隐私与独立部署能力。
