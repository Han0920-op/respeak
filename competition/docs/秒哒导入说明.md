# 秒哒接入 / 导入说明

本作品是**无后端静态前端**。交付同时提供模块版和可移植的单文件版。不同账号、工作台版本的导入入口和能力可能不同；本次未登录秒哒，没有实测平台导入或发布，以下提供可核对的文件与接入步骤，不承诺平台一定支持 ZIP 一键还原项目。

## 推荐文件

- 完整工程：仓库根目录 `respeak-competition-v1.0.0.zip`，解压后的 `competition/`。
- 最容易迁移：`competition/一键预览.html` 或 `competition/dist/standalone.html`，二者内容相同，内含样式、脚本、五张 SVG 插画。
- 标准静态站：`competition/dist/`，必须保持 `index.html`、`src/`、`assets/` 的相对路径。

ZIP 是完整源码交付包，包含文档与截图，**不是保证符合秒哒内部工程格式的专有导入包**。

## 如果工作台支持代码工程或静态 HTML 导入

1. 新建网页/前端项目，查找当前工作台提供的“导入代码”“导入 HTML”或等价能力，以实际界面为准。
2. 支持完整工程时，选择解压后的 `competition/`，设置构建命令 `npm run build`、输出目录 `dist`；Node.js 20+，无需依赖安装步骤。若流程强制执行安装，本工程无第三方依赖，`npm install --ignore-scripts --package-lock=false` 不会安装额外包。
3. 仅支持单 HTML 时，选择 `一键预览.html`；若平台要求入口为 `index.html`，上传前将其副本改名。代码编辑器方式则粘贴整个单文件 HTML，包括内联 `<style>`、模块脚本及 SVG data URI，不要只拷贝页面正文。
4. 不添加任何模型、API Key、数据库、云函数或 Python 服务。禁止让生成流程把固定对话改成模型接口。
5. 在预览中核对五场景、全部七步、点击物件、输入与参考句、本地保存以及移动端；再使用工作台自己的发布流程。

## 如果工作台仅提供对话式生成

可附上单文件 HTML、作品说明和源码 ZIP，并使用以下说明作为迁移需求。此路径是重建/适配，不是字节级导入；迁移后的行为必须重新验收。

> 请把附件《这句话，我想重说》完整静态前端接入此项目。以提供的 HTML、CSS、JavaScript、原创 SVG 和五段剧情为准。保留米白纸感与鼠尾草绿视觉，五个场景及可点物件，以及“进入故事→选择目标→交流→私人暂停→重说一句→原版与新版对比→结束回顾”七步。保留本地 localStorage 记录、删除确认和 JSON 导出。全部人物回应和结局明确标注为预设剧情，自由输入不进行语义分析、不改变结局。不要调用模型，不要求密钥，不生成后端，不添加用户登录或数据上传。保留手机适配和隐私提示。先确认平台能否执行内联 JavaScript/模块脚本与本地存储，若平台沙箱限制，请说明限制，不要假称功能已完成。

## 平台限制时的处理

- 如果导入后只有静态画面，优先检查工作台是否允许 JavaScript/模块脚本；只支持富文本 HTML 的入口无法运行本作品，须改用代码工程或独立静态部署。
- 如果平台禁止 `data:` 图片或内联模块，使用模块版 `dist/`，让代码和 SVG 作为同源文件托管；不要移除平台安全策略。
- 若预览运行在禁用存储的 iframe，本地记录可能仅保留在内存。请打开正式发布站点重新验证；确认保存后刷新仍在，再声称已持久保存。
- 若没有代码导入/执行能力，可独立托管 `dist/` 后在平台中放置跳转入口；能否嵌入取决于工作台能力及目标站点策略。
- 秒哒的预览域名和正式站点域名可能不同，本地记录不自动跨域迁移，必要时先导出。

## 导入后验收清单

1. 五张不同插画与 15 个物件提示可见、可点。
2. 所有选择门槛生效，暂停需要/提醒未选时不能跳过。
3. 自由表达原样展示，HTML 标签不执行。
4. 固定结局明确提示“不分析输入、不保证现实回应”。
5. 手动保存后刷新仍能看到记录，导出 JSON 内容完整，删除需要确认。
6. 在 390px 宽度完整走通一次，无横向溢出。
7. 浏览器网络面板无模型、统计、外部字体或图片请求。

若平台接入受限，仓库中的原始单文件与静态部署版仍可独立使用。
